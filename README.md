# CKM 住院死亡风险计算器

纯 HTML / CSS / JavaScript 静态网站。推理、缺失值插补和输入校验全部在浏览器本地执行，无后端、无 API Key、无第三方 CDN、无分析追踪或输入持久化。

## 本地打开

直接用现代浏览器打开 `index.html`。也可以在此目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173`。Python 只是开发预览工具，不是生产后端。

点击“填入演示数据”，确认适用人群后计算。完整合成病例应显示 **3.4%**；仅勾选碳酸氢盐缺失应显示 **4.4%**。演示数据不是真实患者。修改任何输入后，旧结果立即清除。

## 模型一致性

- 模型：`CKM-SHR-XGB9-20261113`。
- 原 RDS MD5：`b11f762732c4bd257915511652047f40`。
- 20 个锁定 XGBoost 模型，每个含 100 棵树；平均 20 个预测概率。
- 保留原特征顺序、浮点分裂阈值、叶值和 logistic 输出，未重新训练。
- 允许缺失：年龄、碳酸氢盐、呼吸频率、WBC、BUN、MAP。SHR、卒中及房颤必填。年龄缺失仍须明确确认成人适用条件。
- 固定 FCS-PMM：20 次插补、10 轮、5 个候选供体，种子 20261113。
- 插补供体预测值无重复，随机打乱不影响排序结果。导出程序依原 R 抽样顺序推进随机数，并按 64 种缺失组合导出精确近邻秩。抽样序列只依赖缺失组合，不依赖患者输入。
- 供体的预测值与取值按每个插补系统独立排序；不导出原始行号、患者标识、结局、原始数据表或不使用的插补目标。
- 浏览器必须下载模型参数与插补所需供体数值才能计算。这些文件随公开静态网站公开可读。
- 仅支持原网页的固定种子单例计算，不声称复现论文原批量队列插补顺序。

PMM 邻居选择逻辑参考原依赖的 [mice 3.18.0 matchindex 源码](https://github.com/amices/mice/blob/v3.18.0/src/matchindex.cpp)。具体规则以随包 `predict_locked.R` 为准。

## 验证

使用 Node.js 18 或更新版本，在项目根目录运行：

```sh
node verify.cjs
```

扩展核对集共 191 个 R 参考病例，绝对概率误差容限 `1e-7`。包含此前 63 个参考病例，以及全部 64 种缺失组合各两组人工合成输入；另外验证重复计算、插补数量、非法输入拒绝、SHR 缺失拒绝和结局字段不参与预测。实际核对状态及最大误差见 `verification-report.json`。

首版浏览器检查包括完整输入 3.4%、碳酸氢盐缺失 4.4%、修改输入后结果失效、清空、390px 移动布局。

重新导出需要原资料目录与此目录并列，且本机安装原锁定版本的 R 依赖（xgboost 1.7.11.1、mice 3.18.0、jsonlite 2.0.0）：

```sh
Rscript export-model.R
node verify.cjs
```

R 及其依赖只用于开发阶段重新导出和核对，网页运行时不需要。

扩展缺失支持调用原 `predict_locked(..., calculator=FALSE)` 核对。该入口使用同一个冻结插补器，支持六项插补目标；`calculator=TRUE` 额外施加的是原 Shiny 表单仅开放三项缺失的限制。浏览器保留成人范围、阳性数值、诊断编码和明确勾选缺失的输入校验。没有对 SHR 采用均值、中位数或树的默认缺失分支替代原模型规则。若需要允许 SHR 缺失，必须补充并验证相应插补模型。新缺失组合的数值一致性不等于已完成独立临床验证。

## 适用范围

成年患者，符合原研究 CKM 定义，且存活至入 ICU 满 24 小时。预测结局是该节点之后同一次住院期间死亡，不是 24 小时、30 天或长期死亡率。

WBC 使用入 ICU 前 6 小时至后 24 小时的最小值；碳酸氢盐和 BUN 使用首 24 小时最小值；呼吸频率与 MAP 使用首 24 小时均值。SHR 是入院血糖（mg/dL）除以 `[28.7 × HbA1c（%）− 46.7]`。诊断必须在预测节点前已明确，未知不能记为无。

研究演示工具，不替代临床判断。原资料所报内部测试 AUC 0.7758、外部 AUC 0.7937 不是此次前端的独立临床验证。外部数据与开发数据的测量汇总定义不同，模型尚未经前瞻性临床实施评估。不提供个体风险置信区间，不使用任意阈值划分高低危，不据此给出治疗建议。
